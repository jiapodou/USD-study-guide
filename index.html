3–4 Week Study Plan

Assumes you already know USD basics. ~1–1.5 hrs/weekday + a longer weekend block. Each week: watch the matching “Learn OpenUSD” modules → do hands-on reps in usdview/Python → drill the flashcard domains → quiz. Weight your time by exam weight: Composition (23%) and the exchange/pipeline block (15%+14%) dominate.

Week 1 — Foundations refresh + Data Modeling D4 13% · D7 8%

Watch: Setting the Stage · Scene Description Blueprints · Beyond the Basics · Visualization bits (UsdGeom/UsdShade/UsdLux).
Do: Author a mesh from scratch in Python (points/faceVertexCounts/faceVertexIndices), recompute extent, add a primvars:displayColor with each interpolation mode, bind a UsdPreviewSurface, drive diffuse from a primvar via UsdPrimvarReader_float3. Inspect in usdview.
Drill: Flashcard domains D4 + D7. Quiz: D4/D7 subset.
Checkpoint: You can explain attribute vs relationship, value-type roles, primvar interpolation, purpose/visibility/active, and the mesh index math cold.

Week 2 — Composition (the big one) D1 23%

Watch: Composition Basics · Creating Composition Arcs (sublayers, references, payloads, encapsulation, variant sets, inherits & specializes, LIVRPS strength ordering).
Do: Build a shot with department sublayers + sparse overs. Reference the same animated layer twice with different SdfLayerOffset. Set a wrong edit target on purpose and debug why an opinion “vanished.” Trace a value through LIVRPS by hand, then confirm with attr.GetPropertyStack().
Drill: D1 flashcards daily (largest deck). Quiz: D1.
Checkpoint: Recite LIVRPS strongest→weakest, know reference vs payload vs sublayer, defaultPrim semantics, variant-selection strength, and 5 reasons an opinion has no effect.

Week 3 — Aggregation/Instancing + Data Exchange + Pipeline D6 10% · D2 15% · D3 14%

Watch: Asset Structure Principles & Content Aggregation · Asset Modularity and Instancing · Developing Data Exchange Pipelines.
Do: Native-instance a set of assets; build a UsdGeomPointInstancer, add a prototype, hide instances via invisibleIds. Flatten an asset and strip a proprietary dep. Convert USDA↔USDC with usdcat, package USDZ with usdzip, validate with usdchecker. Sketch a USD↔glTF/MaterialX conceptual mapping doc.
Drill: D6, D2, D3. Quiz: D2/D3/D6.
Checkpoint: Native vs point instancing trade-offs, why instance interiors are read-only + how to override, USDA/USDC/USDZ trade-offs, asset interface + reference/payload pattern, model kinds & hierarchy rules, path validation.

Week 4 — Debugging + Customizing USD + full review D5 11% · D8 6%

Watch: re-skim Beyond the Basics (value resolution) + any office-hours/cert videos. Read: Maximizing USD Performance, Scalable Asset Structure.
Do: Use TF_DEBUG flags, wrap a bulk-edit loop in SdfChangeBlock and measure, profile with Trace/TfMallocTag. Skim usdGenSchema on a toy typed + API schema; read about ArResolver, SdfFileFormat, custom kinds, SceneIndex (conceptual depth is enough at 6%).
Drill: D5 + D8, then all domains, cram mode off (let the scheduler surface weak cards). Take the full quiz until ≥80%.
Checkpoint / final: Work the study guide’s 13 sample questions. Re-quiz any domain <75%. Book the exam.

If you only have 3 weeks

Merge Week 1 into a 3-day refresh and fold Week 4’s Customizing USD (6%) into Week 3 — but do not compress Composition (Week 2). Keep the full-review quiz gate.

Daily loop (repeat)

  • 10 min — flashcards: clear everything “Due now” for the week’s domains (scheduler handles spacing).
  • 40–60 min — one video module + immediately reproduce it in code/usdview.
  • 10 min — 5–10 quiz questions in the day’s domain; log misses.
  • Weekend — longer hands-on build + full mixed quiz.

Go/no-go before booking

  • ≥80% on the full quiz two sessions running.
  • Every domain ≥75%.
  • All 13 official sample questions correct with reasoning.
  • Composition flashcards mostly in box 4–5.

What each domain rewards

  • Composition (23%) — LIVRPS, all arcs (sublayer/reference/payload/inherits/variants/specializes), opinion strength, edit targets, layer offsets, defaultPrim, debugging composition.
  • Data Exchange (15%) — USDA/USDC/USDZ trade-offs, importers/exporters, round-trip fidelity, validators, conceptual data mapping, glTF/MaterialX.
  • Pipeline Development (14%) — asset structure/interface, model kinds & hierarchy, flatten, versioning/resolvers, path validation, removing proprietary deps.
  • Data Modeling (13%) — prims/properties, attributes vs relationships, primvars, value types, timeSamples, extent, metadata.
  • Debugging & Troubleshooting (11%) — SdfChangeBlock, TfDebug, Trace/TfMallocTag, composition introspection, asset-resolution issues, load/render perf.
  • Content Aggregation (10%) — native vs point instancing, prototypes, invisibleIds, overriding instanced prims, modular reusable assets.
  • Visualization (8%) — UsdGeom/UsdShade/UsdLux, UsdPreviewSurface, material binding, primvar-driven shading, purpose.
  • Customizing USD (6%) — custom typed/API schemas (usdGenSchema), ArResolver, SdfFileFormat, custom kinds, SceneIndex, building plugins against a USD version.

About this app

A self-contained study tool for the NVIDIA-Certified Professional: OpenUSD Development exam. No server, no build, no network — just open index.html. Progress is stored in your browser's localStorage.

Flashcards use spaced repetition (Leitner boxes)

  • Each card lives in a box 1–5. ✓ Got it promotes it (seen again later); ↺ Again sends it back to box 1.
  • Review intervals grow with the box: 0 → 0 → 1 → 3 → 7 → 14 days. The daily session serves only cards that are due.
  • Cram mode ignores the schedule and drills everything in the selected domains.
  • Filter by domain with the chips at the top (applies to flashcards and the quiz).

Shortcuts

  • Space — flip · ← / → — prev / skip · 1 — Again · 2 — Got it
